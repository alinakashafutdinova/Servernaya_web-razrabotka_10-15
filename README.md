## Лабораторная работа №10 — Добавление рассылки в очередь задач

1. Миграция `2026_11_19_000005_create_jobs_table.php` создаёт `jobs` и `failed_jobs`.
2. `QUEUE_CONNECTION=database` установлен в локальном `.env.example`.
3. Создано задание `app/Jobs/VeryLongJob.php`.
4. В `NewsController::store()` вместо немедленной отправки вызывается `VeryLongJob::dispatch($article->id)`. Сама отправка через `ArticleCreatedMail` выполняется в методе `handle()`.
5. Работник запускается `php artisan queue:work database --tries=3 --sleep=1`.
6. После создания новости задача появляется в `jobs`, а после обработки письмо фиксируется в `storage/logs/laravel.log`, если используется `MAIL_MAILER=log`. Для настоящего email нужен SMTP.

### Локальная установка для преподавателя (без хостинга)

Требуется PHP **8.3+** (pdo_sqlite, mbstring, openssl, fileinfo), Composer или готовая папка `vendor`.

```bash
composer install
php scripts/setup-local.php
```

**Первый терминал:**

```bash
php artisan serve --host=127.0.0.1 --port=8000
```

**Второй терминал:**

```bash
php artisan queue:work database --tries=3 --sleep=1
```

Откройте http://127.0.0.1:8000. Учётные данные локального модератора автоматически записываются в `LOCAL_LOGIN.txt` (не публикуется в Git). Можно запустить всё сразу через `START_MAC.command` или `START_WINDOWS.bat`.

Для демонстрации постановки задачи в очередь **сначала остановите worker**, создайте статью, убедитесь, что в `jobs` есть задание, потом запустите `queue:work`.

```bash
php artisan queue:failed
php artisan test
```

Секреты хранятся только в локальном `.env`; `database.sqlite`, `LOCAL_LOGIN.txt`, `vendor` и логи исключены из Git. Повторная установка **не удаляет** новости.

## Хостинговая версия

Ветка `hosting-laravel13` использует MySQL InfinityFree и отдельный `.env.example` без паролей. Перед загрузкой нужны подготовленные Composer-зависимости, настройки базы и почты. Из-за ограничений бесплатного хостинга указывать `QUEUE_CONNECTION=database` **нельзя, если worker не запущен**, иначе письма навсегда останутся в очереди. Для сайта используем `sync`; для демонстрации именно фоновой очереди предназначена `main`.
