# ЛР №14: обновление InfinityFree без SSH

Этот файл относится к ветке **hosting-laravel13** и работает вместе с предыдущими лабораторными №10–13. Для автоматического запуска в Laravel необходим доступ к cron; **бесплатный InfinityFree его не предоставляет**, а сторонние web-cron-сервисы блокируются защитой платформы.

1. Сохраните резервную копию рабочей базы MySQL (phpMyAdmin → Экспорт) и текущего `.env`. Не публикуйте эти файлы.
2. Получите последний ZIP из GitHub Actions для `hosting-laravel13`. Он содержит `vendor` и собранные frontend-файлы. Замените код сайта, сохранив **существующие** `.env` и таблицы.
3. В phpMyAdmin откройте **именно существующую базу сайта** с таблицами `users`, `articles` и `migrations` и импортируйте файл `deploy/infinityfree_lab14_views_reports.sql`. Он создаст `article_views` и `daily_report_deliveries` и зарегистрирует две миграции. Ничего не удаляет.
4. В сохранённый `.env` добавьте `DAILY_REPORT_DEMO_EVERY_MINUTE=false`. Оставьте `DB_CONNECTION=mysql`, `QUEUE_CONNECTION=sync`, `CACHE_STORE=database` и остальные рабочие значения.
5. В панели модератора (`/management`) есть кнопка **«Отправить статистику за сегодня»**. Она вручную запускает `stats:daily` только для вошедшего модератора. Повторная отправка тому же адресату в этот день пропускается.
6. Если `MAIL_MAILER=log`, письмо **не приходит** на обычную почту: оно сохраняется в `storage/logs/laravel.log`. Чтобы проверить доставку в ящик, настройте рабочий SMTP, не загружая его пароль в GitHub. Возможность SMTP зависит от ограничений хостинга и почтового провайдера.

**Ограничение:** ежедневная автоматическая отправка в 23:59 возможна только там, где cron действительно запускает `php artisan schedule:run`. InfinityFree free этого не делает; обходы через публичные веб-скрипты не предусмотрены.

**Как проверить:** откройте опубликованную новость несколько раз, сохраните комментарий, отправьте отчёт из панели управления; в MySQL должны появиться записи `article_views` и `daily_report_deliveries`. Не проверяйте число просмотров только по счётчику на экране — страница не показывает счётчик, данные сохраняются в SQL.
